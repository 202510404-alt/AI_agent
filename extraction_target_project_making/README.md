# 실시간 협업 화이트보드

여러 사용자가 실시간으로 함께 그림을 그리고 아이디어를 공유할 수 있는 협업 화이트보드입니다.

## 주요 기능

- **실시간 그리기:** 다른 사용자의 펜 스트로크를 즉시 확인할 수 있습니다.
- **보드 방:** 고유 ID로 나만의 협업 공간을 만들거나 참가할 수 있습니다.
- **실행 취소:** 잘못 그린 내용을 쉽게 되돌릴 수 있습니다.
- **이미지 업로드:** 이미지를 올려 아이디어를 더 풍부하게 표현할 수 있습니다.
- **펜 커스터마이징:** 색상과 굵기를 바꿔 자유롭게 그릴 수 있습니다.

## 활용 예시

1. **브레인스토밍:** 멀리 떨어져 있어도 함께 아이디어를 정리할 수 있습니다.
2. **창작 협업:** 스케치, 드로잉, 디자인을 함께 진행할 수 있습니다.
3. **원격 교육/학습:** 시각적인 설명을 쉽게 공유할 수 있습니다.

## 기술 스택

- **프론트엔드:** ReactJS
- **백엔드:** Node.js, Express
- **실시간 통신:** Socket.IO
- **고유 ID:** UUID

## 동작 방식

- 사용자는 새 보드 고유 ID를 만들거나, 기존 ID로 보드에 참가합니다.
- Socket.IO가 클라이언트와 서버 사이에 지속적인 연결을 유지합니다.
- 그리기, 이미지 업로드, 실행 취소 등의 동작이 Socket.IO 이벤트로 전달됩니다.
- 같은 보드에 연결된 모든 클라이언트가 변경 사항을 실시간으로 반영합니다.

## 시작하기

### 1. 의존성 설치

프로젝트 루트에서 서버와 프론트엔드 의존성을 한 번에 설치합니다.

```bash
npm run install:all
```

또는 각각 설치:

```bash
npm install
cd client && npm install
```

### 2. 프로덕션 실행 (빌드 후 이용)

`start.bat` 파일을 실행하면 프로젝트의 모든 준비 과정을 자동으로 처리하고 서버를 시작합니다. 이 스크립트는 다음 단계를 순차적으로 수행합니다:
1. **의존성 설치:** 프로젝트 루트와 클라이언트 폴더의 모든 필요한 패키지를 설치합니다 (`npm install`).
2. **클라이언트 빌드:** React 프론트엔드 애플리케이션을 프로덕션용으로 빌드합니다 (`npm run build`).
3. **서버 시작:** 빌드된 클라이언트 파일을 서빙하고 실시간 통신을 처리하는 통합 서버를 시작합니다 (`npm start`).

프론트엔드를 빌드하고 서버에서 함께 제공합니다.

```bash
# 빌드만
npm run build

# 빌드 후 서버 실행
npm run build:start
```

이미 빌드되어 있다면:

```bash
npm start
```

브라우저에서 [http://localhost:7605](http://localhost:7605) 으로 접속합니다.

### 3. 개발 모드

서버와 프론트엔드를 따로 실행합니다.

**터미널 1 — 서버**

```bash
npm run dev
```

**터미널 2 — 프론트엔드**

```bash
npm run dev:client
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 으로 접속합니다.  
프론트는 `http://localhost:7605` 소켓 서버에 연결됩니다.

## 🔧 설정

환경 변수로 애플리케이션을 설정할 수 있습니다.

```bash
# .env 파일 (선택)
PORT=7605
```

## npm 스크립트

| 명령 | 설명 |
|------|------|
| `npm run install:all` | 서버 + 클라이언트 의존성 설치 |
| `npm run build` | 프론트엔드 프로덕션 빌드 (`client/build`) |
| `npm start` | 빌드된 프론트 + Socket.IO 서버 실행 |
| `npm run build:start` | 빌드 후 서버 실행 |
| `npm run dev` | 서버만 개발 모드(nodemon) |
| `npm run dev:client` | React 개발 서버 (포트 3000) |

## 프로젝트 구조

```
├── index.js          # Express + Socket.IO 서버 (빌드 결과물 서빙)
├── package.json      # 서버 의존성 및 스크립트
└── client/           # React 프론트엔드
    ├── build/        # 프로덕션 빌드 결과 (npm run build)
    └── src/
        ├── Home.js       # 보드 생성/참가 화면
        ├── Canvas.js     # 화이트보드 화면
        ├── socket.js     # 소켓 연결 설정
        └── UploadFile.js # 이미지 업로드
```
