목표는 기존 프로젝트를 리팩토링하는 것이 아니라 **기존 구조를 최대한 유지하면서 기능을 추가**하는 것이다.

# WebRTC 요구사항

기존 Socket.IO 서버를 Signaling Server로 사용한다.

별도의 Media Server는 사용하지 않는다.

Mesh 방식으로 구현한다.

새로운 사용자가 입장하면

기존 참가자들과 각각 PeerConnection을 생성한다.

Offer / Answer / ICE Candidate를 Socket.IO 이벤트로 처리한다.

사용자가 퇴장하면

PeerConnection

MediaStream

Socket Listener

모두 정리한다.

MediaStream Track도 stop() 처리한다.

--------------------------------------------------------

# React 구현 방식

새로운 Hook을 생성한다.

예시

hooks/useWebRTC.js

Hook 내부에서

- localStream

- peerConnections

- remoteStreams

- participantState

를 관리한다.

peerConnections는

Map<socketId, RTCPeerConnection>

형태를 사용한다.

useRef를 활용하여 불필요한 재렌더링을 방지한다.
